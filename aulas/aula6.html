Aula 6: Importação de Assets e Organização de Projeto

Unidade II – Fundamentos da Unity e Prototipagem

Plano da Aula

CONTEÚDO

Importação de assets via Asset Store e repositórios externos; estruturação e organização de arquivos no projeto Unity.

OBJETIVO

Habilitar o aluno a importar e integrar assets no projeto Unity aplicando boas práticas de organização de arquivos, pastas e cenas.

METODOLOGIA

Aula prática com resolução de tarefa orientada (aprendizagem baseada em tarefas reais).

🎯 Resultados de Aprendizagem (Aula 6)

Ao final desta aula, o(a) estudante será capaz de:

  • Importar pelo menos 3 assets (modelo 3D, textura/material e áudio) via Asset Store ou fonte externa, aplicando as configurações de importação adequadas.
  • Organizar a estrutura de pastas do projeto segundo o padrão proposto (_Project/Art, Prefabs, Scenes, Scripts) e separar assets de terceiros em Plugins/ quando aplicável.
  • Configurar compatibilidade com URP (resolver materiais “rosa” e ajustar escala/colisores de modelos).
  • Criar pelo menos 1 Prefab funcional a partir de um modelo importado, com colisor apropriado.
  • Versionar o projeto em um repositório Git com .gitignore e Git LFS para binários, registrando ao menos 3 commits com mensagens descritivas.

✅ Critérios de Avaliação da TED (Aula 6)

1) Importação & Compatibilidade (25%)

  • 0–10%: Assets importados com problemas de materiais/escala; ajustes ausentes.
  • 11–20%: Importação ok; alguns ajustes feitos (ex.: conversão URP), mas ainda há inconsistências.
  • 21–25%: Importação correta; materiais compatíveis, escala adequada e configurações ajustadas.

2) Organização de Projeto (25%)

  • 0–10%: Estrutura de pastas ausente ou confusa; convenções de nomes não seguidas.
  • 11–20%: Estrutura parcialmente correta; pequenos desvios de padrão.
  • 21–25%: Estrutura completa conforme proposto; nomes consistentes e separação de terceiros em Plugins/.

3) Cena Funcional (20%)

  • 0–8%: Cena incompleta ou não executa como esperado.
  • 9–16%: Cena simples e funcional; composição básica.
  • 17–20%: Cena funcional com composição coerente (iluminação básica, posicionamento, uso dos assets).

4) Prefab com Colisor (15%)

  • 0–6%: Prefab ausente ou sem colisor funcional.
  • 7–12%: Prefab criado; colisor presente mas com ajustes pendentes.
  • 13–15%: Prefab correto; colisor apropriado e reutilizável.

5) Versionamento (Git + LFS) (15%)

  • 0–6%: Repositório ausente ou sem .gitignore/LFS.
  • 7–12%: Repo criado; .gitignore ok; LFS parcial; commits pouco descritivos.
  • 13–15%: Repo com .gitignore + LFS corretos e ≥3 commits com mensagens claras.

Construindo Mundos: A Arte de Montar o Quebra-Cabeça

Na aula anterior, configuramos nosso ambiente de trabalho na Unity. Agora, vamos começar a preenchê-lo. Um jogo é um "quebra-cabeça" montado com diversas peças: modelos 3D, texturas, sons, scripts, etc. Essas peças são os assets. Saber como encontrar, importar e, principalmente, organizar esses assets é uma habilidade que acelera drasticamente a prototipagem e evita dores de cabeça no futuro.

Atenção às Licenças de Uso

Nem todo asset encontrado na internet é gratuito para uso em projetos, especialmente comerciais. Sempre verifique a licença (ex: CC0, MIT, Creative Commons). A Unity Asset Store deixa isso claro, mas em repositórios externos, a responsabilidade é sua.

Importação de Assets

1. Unity Asset Store (Oficial)

  1. Abra a Asset Store via Window > Asset Store (ou acesse o site).
  2. Pesquise pelo asset desejado (use filtros como "Free Assets").
  3. Clique em "Add to My Assets".
  4. No Unity, abra Window > Package Manager. No topo, selecione "My Assets".
  5. Encontre o asset, clique em "Download" e depois em "Import".
  6. Uma janela mostrará todos os arquivos do pacote. Revise e desmarque o que não for necessário (ex: cenas de demonstração) e clique em "Import".

2. Repositórios Externos (GitHub, Itch.io)

Assets de fora da loja oficial vêm em vários formatos:

  • .unitypackage: Dê um duplo clique no arquivo ou vá em Assets > Import Package > Custom Package.
  • URL de Git: No Package Manager, clique no ícone "+" > "Add package from git URL..." e cole o link.
  • .zip / Arquivos Soltos: Descompacte e arraste as pastas (ou arquivos como .fbx, .png, .wav) diretamente para a janela Project da Unity.

3. Ajustes de Compatibilidade e Otimização

Após importar, quase sempre é necessário fazer ajustes no Inspector:

  • Materiais Rosas (URP): Use Window > Rendering > Render Pipeline Converter para converter os materiais.
  • Modelos 3D (.fbx): Verifique o Scale Factor, habilite Generate Colliders se necessário, e ajuste as configurações de Normals e Rig.
  • Texturas (.png): Altere Texture Type (ex: Normal Map), habilite/desabilite sRGB, e ajuste Compression para otimizar o tamanho.
  • Áudio (.wav): Habilite Force To Mono para sons 3D, e ajuste Load Type e Compression Format para otimizar o uso de memória.

Checklist: Primeiros 5 Minutos Pós-Import

✅ O asset está na pasta correta? ✅ Os materiais estão funcionando (sem rosa)? ✅ A escala do modelo 3D está correta na cena? ✅ As texturas estão com a configuração adequada (Normal, sRGB)?

Organização do Projeto

Um projeto bem organizado é mais fácil de manter, escalar e trabalhar em equipe. A estrutura de pastas é a espinha dorsal da organização.

Padrão de Pastas

Crie uma pasta principal (ex: _Project ou Game) para separar seus assets dos assets importados. 


Assets/
  _Project/
    Art/
      Models/
      Textures/
      Materials/
      Audio/
        SFX/
        Music/
    Prefabs/
      Characters/
      Props/
    Scenes/
      Main.unity
      Sandbox.unity
    Scripts/
      Player/
      Systems/
      UI/
  Plugins/  (Para assets de terceiros)

Convenções de Nomes

  • Arquivos e Pastas: Use PascalCase (Ex: PlayerController, Art, Prefabs). Evite espaços e caracteres especiais.
  • Prefixos/Sufixos: Ajuda a identificar o tipo de asset rapidamente (Ex: mat_Player, tex_Ground_D, sfx_Jump, Player_Prefab).

Dica de Ouro: Prefabs

Sempre transforme GameObjects complexos em Prefabs. Isso permite reutilizá-los facilmente e qualquer mudança no Prefab original atualiza todas as suas instâncias na cena, evitando trabalho repetido e referências quebradas.

Versionamento com Git/GitHub

Versionar seu projeto é crucial. O Git permite que você salve "fotos" (commits) do seu progresso, reverta mudanças e trabalhe em equipe sem sobrescrever o trabalho dos outros.

Configuração Essencial

Dois arquivos são essenciais na raiz do seu projeto Unity para que o Git funcione corretamente:

.gitignore


# Unity-specific ignores
/[Ll]ibrary/
/[Tt]emp/
/[Oo]bj/
/[Bb]uild/
/[Bb]uilds/
/[Ll]ogs/
/[Uu]ser[Ss]ettings/

# Visual Studio / Rider files
.vs/
*.csproj
*.sln

.gitattributes (para Git LFS) 


# Git LFS for large binary files
*.fbx filter=lfs diff=lfs merge=lfs -text
*.png filter=lfs diff=lfs merge=lfs -text
*.jpg filter=lfs diff=lfs merge=lfs -text
*.psd filter=lfs diff=lfs merge=lfs -text
*.wav filter=lfs diff=lfs merge=lfs -text
*.mp3 filter=lfs diff=lfs merge=lfs -text

Use Git LFS!

O Git não é bom com arquivos grandes e binários (modelos, texturas). O Git LFS (Large File Storage) é uma extensão que resolve isso. É essencial para projetos de jogos.

🧭 Roteiro de Atividade Guiada (45–60 min)

Objetivo: importar assets, ajustar compatibilidade, organizar o projeto e montar uma cena funcional, registrando o progresso com Git/LFS.

Pré-requisitos

  • Projeto URP aberto (Aula 5).
  • Pacote de assets pré-selecionado (local) disponível ou acesso à Asset Store.
  • Git e Git LFS instalados na máquina.

Dinâmica

Trabalho em duplas com papéis alternados:

  • Driver: executa as ações.
  • Navegador: confere checklist e pergunta “o que verificamos agora?”.

Trocar papéis aos 25 minutos.

Planos B

  • Sem internet: usar pacote local (.zip / .unitypackage).
  • Máquina lenta: importar só 1 modelo + 1 textura + 1 áudio.

0–5 min — Alinhamento & Verificação Rápida

  • Abrir o projeto (URP). Confirmar Graphics e Quality com asset URP definido.
  • Garantir que está em Edit Mode (não em Play).

Checkpoint 1: Cena aberta e URP ativo (sem erros de pipeline).

5–15 min — Importação de Assets

  1. Importar 3 assets: 1 modelo 3D, 1 textura/material, 1 áudio.
  2. Ao importar, desmarcar conteúdos não essenciais (ex.: cenas de demo grandes).
  3. Se for .zip: arrastar pastas/arquivos para a janela Project.

Checklist: assets aparecem no Project; nomes legíveis; pastas de terceiros separadas (ex.: Plugins/).

15–25 min — Compatibilidade & Ajustes

  • Materiais “rosa” → usar Render Pipeline Converter para URP.
  • Modelos 3D: checar Scale Factor, normais e Generate Colliders (se fizer sentido).
  • Texturas: definir tipo (ex.: Normal map), checar sRGB e compressão.
  • Áudio: Force To Mono (se 3D), ajustar Load Type e compressão.

Checkpoint 2: Sem materiais “rosa”; escala coerente (1u ≈ 1m) e colisor funcionando.

25–35 min — Organização do Projeto

Criar a espinha dorsal do projeto e padronizar nomes. 

Assets/
  _Project/
    Art/{Models,Textures,Materials,Audio/{SFX,Music}}
    Prefabs/{Characters,Props}
    Scenes/{Main.unity,Sandbox.unity}
    Scripts/{Player,Systems,UI}
  Plugins/   ← assets de terceiros (sem modificar)
  • Mover o que for “nosso” para _Project/; manter terceiros em Plugins/.
  • Criar um Prefab a partir do modelo 3D (com colisor).
  • Aplicar convenções: PascalCase para arquivos/pastas e prefixos quando útil (ex.: mat_, tex_, sfx_).

Checkpoint 3: Estrutura finalizada e Prefab criado em _Project/Prefabs/.

35–45 min — Montagem da Cena

  • Criar/abrir _Project/Scenes/Main.unity.
  • Compor o cenário com o Prefab e outros objetos; ajustar luz direcional/skybox se necessário.
  • Adicionar um AudioSource simples (efeito ou música ambiente).
  • Play test (colisão, escala e áudio).

Checkpoint 4: Cena roda sem erros; composição básica coerente.

45–55 min — Versionamento (Git + LFS)

Inicializar repositório, configurar LFS e fazer commits significativos.

.gitignore (essencial) 

/[Ll]ibrary/
/[Tt]emp/
/[Oo]bj/
/[Bb]uilds?/
/[Ll]ogs/
/[Uu]ser[Ss]ettings/
.vs/
*.csproj
*.sln

.gitattributes (LFS) 

*.fbx filter=lfs diff=lfs merge=lfs -text
*.png filter=lfs diff=lfs merge=lfs -text
*.jpg filter=lfs diff=lfs merge=lfs -text
*.psd filter=lfs diff=lfs merge=lfs -text
*.wav filter=lfs diff=lfs merge=lfs -text
*.mp3 filter=lfs diff=lfs merge=lfs -text
# No diretório raiz do projeto Unity
git init
git lfs install
git add .gitattributes .gitignore
git commit -m "chore: configura Git LFS e .gitignore"

# Adicionar estrutura e assets em etapas para commits descritivos
git add Assets/_Project
git commit -m "feat: estrutura básica de pastas e cena Main"

git add Assets/Plugins
git commit -m "chore: adiciona assets de terceiros em Plugins"

git add .
git commit -m "feat: prefab com colisor e ajustes de compatibilidade URP"

Dica: Commits pequenos contam a história do projeto e facilitam rollback.

55–60 min — Exit Ticket

  • Tirar um print da janela Project mostrando a estrutura e um print/curto vídeo da cena rodando.
  • Responder rapidamente: “Qual ajuste de importação foi mais necessário hoje e por quê?”

Para quem terminar cedo

  • Criar um Prefab adicional com LOD Group ou variações de material.
  • Adicionar um Global Volume leve (Bloom/Vignette) e ajustar exposição.
  • Organizar Labels nos assets para facilitar buscas.

Para quem estiver com dificuldades

  • Usar o pacote local já aprovado (evita incompatibilidades).
  • Importar primeiro 1 modelo + 1 textura + 1 áudio.
  • Pular efeitos e focar apenas na cena funcional e organização.

Quadro do Professor (condução)

  • Use um timer visível para as transições dos blocos.
  • Quando ouvir “deu certo?”, devolva com “o que você verificou no Inspector?” para estimular leitura técnica.
  • Intervenções rápidas: materiais rosas (Converter), escalas absurdas (Scale Factor), áudio mudo (Volume/Spatial Blend).
  • Peça 3 commits mínimos e confira mensagens descritivas (não “update”).

📝 Tarefa (TED): Cena com Assets Importados + Organização

O objetivo é aplicar os conceitos da aula para montar uma cena simples, mas bem organizada.

Passo a Passo:

  1. Crie um novo projeto Unity (URP).
  2. Importe ao menos 3 assets gratuitos (um modelo 3D, uma textura/material e um áudio) da Asset Store ou de repositórios externos.
  3. Aplique a organização de pastas padrão (_Project/Art, Prefabs, Scenes, Scripts).
  4. Crie uma cena simples em _Project/Scenes/Main.unity usando os assets importados.
  5. Entrega: Poste no Moodle um print OU um vídeo curto mostrando a estrutura de pastas na janela Project e a cena funcional.
  6. Nome do Projeto: NOME_SOBRENOME_TDJD_AULA6

Extensões (Opcional)

Para um desafio extra: crie um Prefab com o modelo 3D e um colisor configurado; corrija a escala de um FBX importado; adicione um efeito de pós-processamento leve à cena.
